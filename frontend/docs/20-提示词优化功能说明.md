# 提示词优化功能说明

本篇说明提示词优化服务、界面与用法，便于结合 AI 工作流提高提示质量。

## 概览

- 服务文件：`src/services/promptOptimizationService.ts`
- UI 演示：`src/pages/PromptOptimizerDemo.tsx`（访问：`/app?prompt-demo`）
- Hook：`src/hooks/usePromptOptimization.ts`
- 默认模型：`gpt-5.6-luna`
- 可选模型：`gpt-5.6-luna`、`gpt-5.6-terra`

## 服务特性

- 超时策略：单次真实请求最多等待 120 秒，并通过底层 `AbortController` 真正取消；不做前端自动重试，避免旧实现超时后请求仍在后台运行并产生重复调用。
- 规范化输出：强制单段文本、去除多余换行/空白
- 可配置项：`model`、`language`（中文/English）、`focus`、`tone`、`lengthPreference`
- Flow Prompt Optimizer 将模型保存到节点的 `promptOptimizationModel`，标题栏使用原有紧凑胶囊标签，点击标签在浮层中切换模型；积分预览和实际运行读取同一字段，旧节点或非法值回退到 Luna。
- AI Chat 长按提示词扩写按钮打开的助手面板使用同一组 Luna / Terra，自动扩写沿用面板当前选择。
- 后端只允许两种已验证的优化模型，并固定通过 new-api Right 文本接口执行；客户端旧值（包括 `gpt-5.4`、`deepseek-v4-flash`）会在版本迁移时归一到 Luna。网关最后一跳分别映射为 `tanvas-right-gpt-5.6-luna`、`tanvas-right-gpt-5.6-terra`，用专用模型 ID 锁定 Right channel。
- 调用 Right GPT 前，后端固定先让 new-api 的 `deepseek-v4-flash-260425` 对本次真实请求做语义审核。只有判定同时满足“不违反政治合规、不包含敏感话题”才继续；拒绝、审核服务失败或审核结果无法验证时都不会调用 GPT，也不会由前端关键词规则或其他模型静默兜底。
- 提示词优化器不读取也不发送画布快照，不发送小T专用的 session、`mode`、工具白名单或 durable turn 字段；响应使用普通同步 OpenAI Chat JSON。

### 请求/响应

输入：
```ts
type PromptOptimizationRequest = {
  input: string;
  model?: 'gpt-5.6-luna' | 'gpt-5.6-terra';
  language?: '中文' | 'English';
  focus?: string;
  tone?: string;
  lengthPreference?: 'concise' | 'balanced' | 'detailed';
};
```

输出：
```ts
type PromptOptimizationResult = {
  optimizedPrompt: string;
  model: string;
  tokenUsage?: number;
};
```

## 使用方法

1) 打开 `/app?prompt-demo` 进入测试台
2) 填写“原始描述”，可选设置语言/语气/重点/长度
3) 点击“生成优化提示”，复制结果到 AI 生成/编辑/融合场景中使用

## 服务配置

- 浏览器不持有模型供应商密钥；请求统一发送到 Tanva 后端，再由 `NEW_API_BASE_URL` / `NEW_API_KEY` 访问 new-api。
- new-api 的 default 分组还必须提供可用的 `deepseek-v4-flash-260425` ability，供 Right GPT 之前的安全审核使用；该模型是内部审核步骤，不出现在生成模型选择器中。
- new-api 必须配置 type 60 的 `right` channel，并为 default 分组注册 `tanvas-right-gpt-5.6-luna`、`tanvas-right-gpt-5.6-terra` abilities；model mapping 分别指向 Right 的 `gpt-5.6-luna`、`gpt-5.6-terra`。Right channel 的 base URL 是 `https://rightapi.ai/codex`，由适配器补 `/v1/chat/completions`，不得写成会产生双重 `/v1/v1` 的地址。

## 最佳实践

- 输出语言与目标一致：中文内容优先中文输出
- 需求不充分时补足背景但不偏题
- 针对融合/编辑任务，在优化后的提示中保留明确操作指令
