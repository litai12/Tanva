# Node模式使用指南

## 概述

Node模式是Artboard应用中的一种专门的可视化编程模式，允许用户通过拖拽和连接节点的方式创建复杂的工作流程。该模式特别适合创建AI图像生成流水线、数据处理管道以及多步骤的创意工作流。

## 模式切换

### 如何进入Node模式
1. 在应用顶部导航栏中找到模式切换器
2. 点击右侧切换到"节点模式"
3. 界面将切换到Node编辑环境

### 模式特性
- **可视化编程**: 通过节点和连线构建逻辑流程
- **实时预览**: 节点处理结果可即时查看
- **模块化设计**: 每个节点负责特定功能
- **数据流驱动**: 数据在节点间流动和转换

## 可用节点类型

### 1. Prompt Node (文本提示节点)
- **功能**: 输入AI图像生成的文本描述
- **输入**: 无
- **输出**: 文本提示信息
- **使用方法**: 
  - 点击工具栏中的文本图标 (T) 添加
  - 在节点中输入描述文字
  - 支持多行文本和详细描述

### 2. Image Node (图像节点)
- **功能**: 输入、存储和传递图像数据
- **输入**: 图像文件或来自其他节点的图像
- **输出**: 图像数据
- **使用方法**:
  - 点击工具栏中的图片图标添加
  - 拖拽图片文件到节点区域
  - 或点击"上传"按钮选择文件
  - 双击图像可全屏预览

### 3. 3D Node (3D模型节点)
- **功能**: 处理和渲染3D模型
- **输入**: 3D模型文件或相关参数
- **输出**: 渲染后的图像或3D数据
- **使用方法**:
  - 点击工具栏中的立方体图标添加
  - 上传3D模型文件
  - 调整渲染参数

### 4. Camera Node (相机节点)
- **功能**: 捕获画布快照或相机输入
- **输入**: 画布状态或外部相机
- **输出**: 捕获的图像
- **使用方法**:
  - 点击工具栏中的相机图标添加
  - 配置捕获参数
  - 触发拍照操作

### 5. Generate Node (生成节点)
- **功能**: 执行AI图像生成任务
- **输入**: 文本提示、参考图像等
- **输出**: AI生成的图像
- **使用方法**:
  - 点击工具栏中的星星图标添加
  - 连接Prompt Node和其他输入节点
  - 配置生成参数
  - 执行生成任务

### 6. Text Chat Node (纯文本交互节点)
- **功能**: 聚合多个文本提示并调用AI模型返回纯文本回复
- **输入**: 来自多个 Prompt/Optimize/Analysis 节点的文本输出，可额外填写手动描述
- **输出**: 纯文本（自动同步到下游节点的 `prompt/text` 输入）
- **使用方法**:
  - 在工具栏中选择文字交互或在添加面板里选择 `Text Chat Node`
  - 将多个文本节点连接至左侧 `prompt` 端口，节点会自动拼接为请求内容
  - 可在节点内填写追加描述，并根据需要开启启用联网搜索
  - 点击 `Run` 执行，请求完成后回复会显示在回复区域并可继续传递给生成节点

### 7. Video Analysis Node（视频分析与分镜表）

- **功能**：读取完整视频，识别剪辑点、镜头、景别、运镜、构图、台词、特效以及镜头内短时动作/面部肌肉变化，并把结果转换成可编辑的分镜表。
- **输入**：左侧 `video` 端口连接远程视频节点。
- **模型**：节点内独立选择豆包 Seed 2.0 Mini/Lite/Pro 或 Gemini 2.5 Flash/3.5 Flash/3.1 Pro；默认豆包 Seed 2.0 Lite，不跟随工作区全局图片模型。
- **豆包计费**：Pro/Lite/Mini 均按视频真实时长计费，价格分别为标准付费 Seedance 2.0 480P 的 `1/3`、`1/10`、`1/20`；当前即 Pro=`125/3`、Lite=`12.5`、Mini=`6.25` 积分/秒，先计算整段视频总价再向上取整。节点读取媒体时长展示运行前预估，实际扣费以后端 `ffprobe` 识别时长为准。Responses API token usage 仅用于内部上游调用审计，不参与三种豆包模型的用户侧扣费；供应商成本、内部倍率与价格快照不在公开界面展示，实扣会进入积分明细。
- **输出**：
  - 分析完成后自动在右侧创建或更新“分镜表” Prompt。
  - 表格竖轴是镜头内时间段，横轴按模型实际返回字段动态生成。
  - 可切换“表格/原文”；修改表格会同步更新 Prompt 原文，也可回到原文做整段二次编辑后重新生成表格。
  - 选中分镜表 Prompt 后，可新增同镜头时序行、新增镜头、复制/删除行，以及新增、重命名、删除列，自行调整行列数量。
  - 每列可切换为“镜头列”或“时序列”：镜头列修改会联动同一镜头的全部时间行，时序列只修改当前行。删除或重命名“镜号”列不会破坏内部镜头分组。
  - 表格上方提供横向浏览滑块与左右翻页按钮；也可使用 `Shift + 滚轮` 横向移动，表头与时间列在滚动时保持固定。
  - 表格单元格内可直接输入 `@`，也可选中单元格后点击“@ 资产”，从工作流、项目库或个人库选择图片资产；引用会保存为标准 Prompt mention，支持预览定位、整体删除及下游图片/视频节点读取。
  - 支持导出 `.xlsx`，以及从 `.xlsx` 导入；动态列、镜头总览、镜头分组和镜头列/时序列设置会一并往返。
  - 除了由视频分析自动生成，也可直接从“添加节点 → 文字类节点”创建“分镜表节点”；新节点会带完整默认动态列和一条可编辑空镜头。
  - 分镜表标题栏提供“剧本转分镜”：弹窗分为 Skill 与剧本两部分，均可粘贴文字或上传 `.txt`、`.md`、`.markdown`、`.docx` 填充。生成时严格按当前动态列回填并切回表格视图。
  - 内置“自然主义快节奏分镜” Skill 会先判断输入类型：普通剧本进入拆镜创作，可增加特写、反应镜头和空镜等拍法但不增加剧情；已有镜号/时间码的分镜进入锁镜精修，镜号、镜数、顺序和时长不变，只补足视线、表情、呼吸、细微动作及衔接。
  - 新建空分镜表默认包含镜号、时间区间、时长、节拍单元、剧本特征、场景与光影、起始站位、景别、运镜、构图、画面内容、台词、音效、备注、字数/语速及镜头内表演细分。默认节奏以约 15 秒为节拍、单镜不超过 3 秒、每集目标 90–120 秒；超过 8 个汉字的中文台词换机位延续，英文台词不超过 3 词/秒。
  - 镜头细化不得停留在“起始—过渡—结束”的动作概述。每镜至少交代起始几何状态、动作动力链、运动路径、速度曲线、机位响应、焦点/景深、光影/遮挡、结束状态与声音；可见动作超过 1 秒时至少拆成 3 个首尾相接且状态真实变化的时序段，3 秒动作镜头通常使用 4 段。手部/面部/关键道具特写还需锁定数量、身份、关节/轮廓和材质纹理，阻止增指、融指、反折、漂移与无来源形变。
  - Skill 要求保留全部 `@` 标注，使用场景参照物描述站位和运动，保持人物/道具/衣物/光影连续；OS 作为画外音且人物闭唇。全程无音乐、只保留音效、不生成字幕。模型返回既有可解析层级文本，节点界面负责表格化展示。
  - 剧本转分镜直接使用小T对话当前所选大脑模型（小T-5.6 Luna / 小T-5.6 Terra / 小T-DeepSeek V4 Flash），不提供另一套模型状态。
  - Skill 可存入当前账号的 Skill 库，在该账号所有项目和设备中复用；已保存 Skill 可在弹窗中更新或删除，其他账号不可访问。
  - 它仍是标准 Prompt 节点，可 resize、改标题，并连接所有接受 Prompt 的图片/视频节点。
- **使用方法**：
  1. 视频分析路径：将视频节点连接到 Video Analysis 的 `video` 输入，选择分析模型并点击“分析”，等待右侧生成分镜表 Prompt。
  2. 剧本路径：从“文字类节点”直接添加“分镜表节点”，点击标题栏“剧本转分镜”，选择/编辑 Skill 并粘贴或上传剧本，然后生成回填。
  3. 在表格中校正时间、动作或镜头字段；按需通过工具栏增删行列、改列名、切换列作用域、引用 `@` 资产或导入/导出 Excel，也可进入“原文”完成整段二次编辑。
  4. 把该 Prompt 连接到后续图片或视频生成节点。

## 节点操作

### 添加节点
1. 使用左侧工具栏中的节点按钮
2. 点击对应图标在画布中添加节点
3. 节点将出现在画布中心位置

### 连接节点
1. 将鼠标悬停在节点的输出端口（右侧圆点）
2. 按住并拖拽到目标节点的输入端口（左侧圆点）
3. 释放鼠标完成连接
4. 连线表示数据流向

### 节点配置
1. 选中节点查看属性面板
2. 在节点内部直接编辑内容
3. 调整节点参数和设置
4. 配置输入输出选项

### 节点管理
- **移动**: 拖拽节点标题栏
- **调整大小**: 拖拽节点边缘的调整手柄
- **删除**: 选中节点后按Delete键
- **复制**: Ctrl+C 复制，Ctrl+V 粘贴

## 工作流创建

### 基础图像生成流程
```
Prompt Node → Generate Node → Image Node
```
1. 创建Prompt Node，输入描述文字
2. 添加Generate Node作为生成器
3. 连接Prompt到Generate的输入
4. Generate的输出连接到Image Node
5. 执行生成任务

### 视频转分镜提示流程
```
Video Node → Video Analysis Node → Storyboard Table Prompt → Image/Video Generate Node
```
1. Video Analysis 读取视频并按剪辑点和短时动作输出层级文本。
2. 系统自动把层级文本解析成分镜表 Prompt；提示词新增字段会自动成为新列。
3. 表格修改、行列增删、列重命名与列作用域调整都会同步回标准 Prompt 文本；原文二次编辑后也能重新解析为动态表格，下游节点始终读取当前分镜内容。

### 图像编辑流程
```
Image Node → Generate Node → Image Node
    ↑             ↑
Prompt Node -------┘
```
1. 上传原始图像到Image Node
2. 创建编辑提示的Prompt Node
3. 将两者连接到Generate Node
4. 输出到新的Image Node

### 3D渲染流程
```
3D Node → Camera Node → Image Node
```
1. 加载3D模型到3D Node
2. 配置Camera Node的视角参数
3. 渲染结果输出到Image Node

## 最佳实践

### 节点布局
- **从左到右**: 按照数据流方向排列节点
- **分层组织**: 相关节点放在同一水平线
- **留白充足**: 节点间保持适当距离
- **逻辑分组**: 使用视觉分组组织复杂流程

### 参数设置
- **明确输入**: 确保每个节点的输入数据完整
- **测试连接**: 定期检查节点间的连接关系
- **参数调优**: 逐步调整参数获得最佳效果
- **保存快照**: 记录重要的参数配置

### 性能优化
- **避免循环**: 确保数据流是有向无环图
- **缓存利用**: 重复使用已处理的结果
- **分步执行**: 将复杂流程分解为小步骤
- **资源监控**: 注意内存和处理时间

## 调试和故障排除

### 常见问题
1. **节点无法连接**
   - 检查数据类型是否匹配
   - 确认输入输出端口对应关系
   - 验证节点状态是否正常

2. **生成失败**
   - 检查Prompt Node内容是否完整
   - 确认Generate Node参数设置
   - 查看错误信息和日志

3. **性能缓慢**
   - 减少同时处理的节点数量
   - 优化图像分辨率设置
   - 清理不必要的中间结果

### 调试技巧
- **分段测试**: 逐个测试节点功能
- **数据检查**: 验证每个节点的输出
- **日志查看**: 关注控制台错误信息
- **简化流程**: 从最简单的流程开始构建

## 与Chat模式的区别

| 特性 | Node模式 | Chat模式 |
|------|----------|-----------|
| 交互方式 | 可视化拖拽 | 文本对话 |
| 适用场景 | 复杂工作流 | 快速生成 |
| 学习曲线 | 中等 | 简单 |
| 可控性 | 高 | 中等 |
| 可重用性 | 高 | 低 |
| 调试能力 | 强 | 弱 |

## 结语

Node模式为专业用户提供了强大的可视化编程能力，特别适合创建复杂的AI工作流程。通过合理的节点布局和连接，可以构建出高效、可重用的创作流水线。

建议初学者从简单的线性流程开始，逐步掌握各种节点的使用方法，再进阶到复杂的分支和循环结构。
