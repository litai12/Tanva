# 签到与免费积分生命周期修正

## 背景

现有实现把签到奖励写入永久 `gift` 批次，并把每日免费积分衰减范围收窄到受邀注册初始额度；同时使用“历史上是否支付过”判断免衰减。结果是多日签到积分持续累积，邀请奖励也没有 lot 可供精确衰减。

## 业务口径

- 签到积分仅在当前签到业务日有效，业务日于本地时间凌晨 3 点切换；当前有效月卡、年卡与 VIP 白名单暂停清理，资格失效后所有跨业务日签到积分一次性清除。
- 当前无有效 VIP 的用户，其邀请奖励、运营赠送、受邀注册免费额度等普通免费积分池每天默认衰减 50；签到积分不参与此衰减。
- 当前有效 VIP 或 VIP 白名单暂停每日 50 衰减；历史充值记录不构成豁免。
- `gift` 全部属于免费可衰减积分；充值本金和充值赠送统一归类为 `recharge`，不参与衰减。

## 设计

- 免费签到奖励创建 `fixed_window` gift lot，`expiresAt` 指向下一个凌晨 3 点；VIP 签到奖励创建当前资格有效时跨日保留的 permanent gift lot，资格失效后由签到清理任务一次性清除。
- 余额查询和所有个人扣费/调整入口在账户锁内即时清理过期签到 lot；每日 3 点任务做全量兜底。
- 历史 permanent 签到 lot 与无 lot 签到流水按业务日兼容清理。
- 免费积分日衰减改为按当前有效 VIP 判定，并扣减全部 `gift` lot；充值本金/赠送统一使用 `recharge`，历史误标充值赠送同步回填。
- 新邀请奖励创建 `gift` lot；历史无 lot 邀请奖励只在存在 legacy balance 时兼容衰减。
- 前端只对存在免费签到到期批次的用户展示具体到期时间，并明确会员/白名单仅在资格有效时暂停衰减。

## 验证

- 纯函数测试覆盖 3 点业务日边界与签到到期点。
- 免费积分分类测试覆盖签到/邀请/受邀注册为可衰减，充值本金/充值永久赠送/会员额度为不可衰减。
- 后端 TypeScript 构建、前端生产构建和改动文件定向 lint 通过。
