## 需求

升级“剧本转分镜”的内置 Skill，使普通剧本可以生成自然主义、快节奏、可直接执行的精细分镜，同时让已有镜号和时间码的分镜只做内容精修：

- 不改剧情、人物关系、台词、OS、关键动作和因果顺序。
- 普通剧本按约 15 秒节拍组织，每集目标 90–120 秒，单镜头默认不超过 3 秒。
- 用特写、反应镜头、空镜和细节动作丰富拍法，但不凭空增加事件、人物、道具或信息。
- 已有分镜进入锁镜精修，保持镜号、镜数、顺序和时长不变。
- 保留全部 `@角色` 标注，明确自然主义表演、人物站位、跨镜连续性、光影和对白语速。
- 默认分镜表包含镜号、时长、景别、运镜、画面内容、台词、音效、备注等可执行字段。

## 设计

1. 把较长的导演规则从转换请求文件拆到纯文本常量模块，便于单独维护和测试。
2. Skill 提供两个互斥工作模式：
   - 拆镜创作：输入是普通剧本时，可增加拍摄镜头，但不得增加剧情事实。
   - 锁镜精修：输入已有镜号/时间码时，不增删、重排或改时长，只填充表演与画面细节。
3. 冲突优先级固定为：剧情/台词/`@` 保真与安全 > 锁镜约束 > 连续性 > 对白可听清 > 快节奏与镜头丰富度。
4. 空分镜表改用面向剧本生产的默认列，同时保留解析器对历史视频分析字段的识别能力。
5. 仍由现有动态列模板控制最终输出，不让 Skill 自行增加字段或返回 Markdown 表格。
6. 增加静态契约测试，覆盖双模式、15 秒节拍、90–120 秒、3 秒切镜、中英文对白限制、`@` 标注、OS 和全局声音规则。
7. 根据用户给出的 3 秒手掌动作反馈，新增“八层镜头细节”质量线：起始几何状态、动作动力链、路径、速度、机位、焦点、光影/遮挡、结束状态/声音；超过 1 秒的可见动作至少拆为 3 个状态真正变化的时序段，并以同一手掌动作为四段颗粒度示例。手部、面部和关键道具特写同时加入数量、身份、关节/轮廓、纹理与遮挡关系的结构稳定约束。

## 验收标准

- 内置 Skill 完整表达用户给定的自然主义、空间、连续性、光影、镜头、对白与安全要求。
- 普通剧本与已有分镜不会因“多加特写”和“零增减镜头”两条冲突要求产生不确定行为。
- 新建分镜表默认出现镜号、时长、景别、运镜、画面内容、台词、音效、备注及精细表演字段。
- 所有镜头和时序字段继续通过既有 parser/serializer 往返，标准 Prompt 协议不变。
- 输出不能只把动作改写成“起始—过渡—结束”；内置示例必须在不增加剧情事实的前提下明显高于用户样例的动作、镜头和光影颗粒度。
- 手部特写必须保持同一只手与五指身份连续，并显式禁止增指、缺指、融指、反折和轮廓漂移。
- 前端针对性测试、lint 与 build 通过；知识库和用户文档同步。
