# 变更提案：节点模型用户消费运营策略

## 背景

托管模型现有 `pricing.v2` 同时承担刊例价格和最终扣费，无法在不改动基础定价、上游成本及请求参数的前提下，对某个模型或某组规格配置限时折扣，也无法单独暂停一个规格并在 Flow 展示原因。

## 目标

1. 在厂商定价书下增加独立的 `consumerPolicies`，只作用于 Tanva 用户最终扣减积分。
2. 策略可作用于整条节点线路，或复用定价维度条件精确筛选型号、分辨率等规格。
3. 折扣、禁用、优先级、开始和结束时间均可在后台管理；时间窗采用 `[startsAt, endsAt)`，结束后自动恢复刊例积分。
4. Seedance 2.5 默认运营配置：
   - 1080P 在 `2026-08-14 14:00` 至 `2026-09-17 14:00`（Asia/Taipei）按刊例积分的 `72%` 扣减。
   - 4K 暂停开放，Flow 显示“暂未开放”，服务端拒绝绕过 UI 的提交。

## 设计

- 基础 `matchingRules/evaluators` 继续输出刊例价格和刊例积分。
- `consumerPolicies` 独立匹配。同一请求中，可用性和折扣分别取最高优先级的有效策略，支持“模型级活动 + 规格级覆盖”。
- 实扣在统一 `resolveEffectiveCreditsQuote` 的最终阶段执行，个人和团队预扣共用结果；审计快照同时记录刊例积分、倍率和实际积分。
- 有精确刊例金额时先按金额乘倍率，再按 `100 积分 = 1 元` 向上取整，避免对已取整积分再次打折产生误差。

## 非目标

- 不改变 Ark/new-api 的请求价格、供应商成本或 catalog 刊例价。
- 不修改 Seedance 2.5 的生成参数和模型路由。
- 不在活动结束时写回或删除配置；过期策略保留用于运营审计，但运行时自动忽略。
