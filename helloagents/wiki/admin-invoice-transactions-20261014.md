# Admin 成功交易与支付宝充值发布

## 功能

- 积分详情新增支付宝充值摘要，微信、支付宝及会员摘要覆盖全部历史成功订单；最近订单展示真实支付渠道。
- “开发票”打开交易核对弹窗，仅显示当前用户的全部成功交易，每页 20 条，包含会员、个人充值和团队交易；展示订单号、支付平台交易号、类型、渠道、金额、支付时间和成功状态。
- `GET /api/admin/users/:userId/paid-orders?page=1` 按用户 ID 精确过滤 `status=paid`，固定每页 20 条；金额汇总为全部成功订单人民币金额。沿用管理员鉴权，普通用户不可访问。
- 弹窗支持加载、空态、失败重试、关闭重开、请求竞争保护及 Escape/遮罩关闭；关闭子弹窗后保留积分详情。当前入口仅用于交易核对，不生成税务发票或修改开票状态。
