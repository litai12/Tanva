# Admin 邀请人手机号查询与人数

- 在原手机号／邮箱／昵称搜索旁新增独立邀请人手机号条件，按完整号码精确查询既有邀请关系；服务端忽略首尾空白，空条件不筛选。
- 两项条件通过搜索按钮或回车提交，提交回第一页，翻页保留条件；清除筛选恢复全部用户。
- 人数来自服务端 `pagination.total`，覆盖全部匹配页。只按邀请人查询时显示该邀请人的邀请总人数；组合用户关键词时明确显示筛选匹配人数。
- 请求和显示结果绑定已提交条件；加载、失败及过时响应不冒用旧人数。
- 延续管理员权限，邀请码兑换与积分规则不变，无数据库迁移。
