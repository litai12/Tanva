# GPT-Image-2.6 普通版（Flare / Sunburst）接入（2026-11-08）

## 范围

新增公开型号 `gpt-image-2.6-flare`、`gpt-image-2.6-sunburst`，合同与定价完全对齐 2.5 普通版：

- 1K / 2K / 4K = 20 / 30 / 40 积分（网关 CNY 0.2 / 0.3 / 0.4，`ModelPrice` 从对应 2.5 变体复制，分辨率倍率 1 / 1.5 / 2）。
- 质量固定 high（不展示质量控件），参考图只接受远程 URL，单图。9:21 与 2.5 普通版同样映射到 9:16。
- 画布：在原 GPT-Image-2.5 节点型号下拉中追加两项（顺序：2.5 Flare、2.5 Sunburst、2.6 Flare、2.6 Sunburst、2.5 VIP×2），默认仍为 2.5 Flare，历史节点不迁移。小T协议、TapCanvas 规划展开、服务端一键成片的型号枚举同步追加。

## 上游合同

| 渠道 | 公开型号 → 上游 | 关键参数 |
| --- | --- | --- |
| ToAPIs（type 59，toapis.com/.cn/.xyz） | 同名直连 | `size` 比例 + `resolution` 1K/2K/4K，网关强制 `quality=high`、去掉 `aspect_ratio`（[文档](https://docs.toapis.com/docs/cn/api-reference/images/gpt-image-2.6/generation)） |
| APIMart（渠道 9） | → `gpt-image-2.6-ext`，`version=flare/sunburst` | 与 2.5-ext 相同：顶层 size/resolution，不传 quality（[文档](https://docs.apimart.ai/cn/api-reference/images/gpt-image-2.6-ext/generation)） |

APIMart 另有同名 `gpt-image-2.6-flare/-sunburst`，那是按 token 计费、quality 可选（auto 按 max 预留）的 VIP 档；经用户确认普通版走 Ext，避免成本高于零售价。2.6-ext 文档未列 `X-APIMart-Response-Version` / `Idempotency-Key`，因此只对 2.5-ext 保留这两个请求头。
