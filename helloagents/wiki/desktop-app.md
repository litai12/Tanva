# Tanva 桌面端

## 定位

Tanva 桌面端采用“Codex 式任务线程、画布按需作为工具面、任务可观察、能力可安装”的产品架构：

- 小T是唯一 AI 对话与工作流编排核心；
- Tanva 画布是通过统一合同注册的第一方内置插件，对应 Codex 在任务中调用的 Browser panel；M0 随应用发布，不提供卸载；
- JZXZ 作为首批能力参考，优先吸收 SketchUp/Rhino/Grasshopper/AutoCAD/Photoshop MCP、本机隔离运行时、动态 Skills、本地 RAG 与 CAD/3D 交付证据；
- 线程内工具活动和左侧任务历史共同呈现异步任务状态与交付证据；
- 未来插件通过统一 manifest、工具 schema、权限与任务协议接入。

桌面端同时执行“一个功能只有一个唯一入口”的硬约束：左侧按 `Work / Chat` 组织任务，Chat 不绑定项目，Work 必须绑定一个项目；任务可拖入项目变为 Work，也可拖回 Chat 解除绑定。`WORK` 标题右侧 `+` 唯一负责创建项目；Work、Chat 和每个项目目录都可折叠，拖入任务会自动展开完整目录路径；项目行本身只负责展开/收起，项目 `…` 负责置顶、重命名和删除。点击 Work 但没有项目时复用同一创建框，不自动生成空项目。项目、任务及画布是三个正交状态：打开项目只切换画布上下文，不得重建桌面任务会话或让任务从侧栏消失。项目菜单、任务菜单、扩展与账号弹层在点击外部、窗口失焦或按 Escape 时关闭，同层菜单互斥。当前任务顶栏提供唯一且不换行的“画布 / 隐藏”开关，只在 Work 显示；小T自动唤起复用同一个右侧工具面，但用户手动隐藏后，本轮后续画布补丁不得再次顶开。最大化/恢复/关闭只出现在工具面标题栏。扩展列表只陈述内置插件，除连接器配置外不提供重复启动按钮。左下角统一展示账号、当前个人/团队、可用余额和团队切换。

项目本身可以直接发起任务：项目行右侧常驻的 `+` 是唯一入口，点击后创建全局桌面会话、立即绑定该项目、展开 Work/项目目录并切换到新任务。它与 `WORK` 右侧只负责创建项目的 `+` 职责分离，也不会与项目行的展开动作混淆。

桌面登录态是长期设备会话：首次登录后，access/refresh token 通过 Electron `safeStorage` 写入操作系统加密存储，渲染器只保留运行期内存副本；旧版 localStorage token 会在首次启动时无感迁移并删除明文。启动顺序固定为“恢复加密令牌 → 恢复本地用户 → 展示桌面壳 → 后台按真实 JWT 签发时间续期”，弱网不应先跳登录页。服务端允许同账号网页、桌面和多台设备并存，refresh/logout 只匹配并轮换当前提交的 refresh token；只有明确退出、refresh token 到期/撤销或账号禁用才清理本地登录态。

视觉层采用 Codex 的任务壳层比例与面板关系，但不复制其品牌皮肤：沿用 Tanva 几何蓝色品牌标、纯白/Premium Black 画布、轻量液态玻璃、圆形工具按钮、小T彩雾任务光环和既有 React Flow 节点。米白暖色页面、薄荷绿主色、重型后台导航和新节点皮肤不属于 Tanva 桌面端。

详细产品合同和 v4 原型见 `frontend/docs/desktop/01-桌面端三态交互与能力架构.md`。

## 任务外壳与画布工具面

1. **任务线程**：左侧任务历史，中间小T线程与输入器；画布不预加载。
2. **画布侧面工具面**：用户从任务顶栏手动展开，或由小T调用后自动展开；两者打开同一个实例。线程负责目标与确认，画布承载项目事实和产物。
3. **最大化画布工具面**：复杂操作时放大同一个侧面工具面，左侧任务边栏继续保留。
4. **文件工作台**：PPT、Excel 与文档作为文件产物在右侧独立预览；需要节点编排或逐页视觉编辑时再交接到画布。
5. **媒体预览**：点击聊天中的图片，在 `tanva.media-preview` 右侧工具面查看、下载或切换同组图片；任务线程继续保留，不打开全屏模态框。

三种布局投影共享同一用户、项目、Flow/章节、会话、选区和稳定任务身份。工具面打开、最大化、恢复和关闭不得创建平行会话、重复提交任务或丢失后台执行。

## 目标进程边界

- Electron Main：窗口、协议、系统权限、更新与签名验证；
- 沙箱化 Renderer：React 对话、项目、画布与任务 UI；
- 小T Bridge：会话、技能、工具与工作流编排；
- Capability Host：插件权限、本地任务、MCP 与可选重型运行时；
- Tanva/TapCanvas 服务：认证、项目、AI、任务、计费和远程资产。

## 当前实现（M1 基础）

- Electron Main/Preload 已落地，Renderer 开启 `contextIsolation` 与 sandbox，关闭 Node integration；
- 主窗口关闭、窗口 IPC 与系统退出统一进入受控退出生命周期：本机连接器清理完成或超时后 Electron 必须结束；macOS 不保留 Dock/后台常驻进程。网页保留 `beforeunload` 离站保护，Electron 依赖自动保存并在明确退出时由 Main 放行 unload，避免不可见的 macOS 提示卡住进程；
- Electron 环境进入独立 `DesktopApp`，网页版本保持原路由；
- 已实现任务边栏、嵌入式小T线程、项目上下文和统一右侧工具面；
- 已实现插件 manifest 校验、注册表、工具面状态、尺寸持久化和错误隔离；
- 工具面宽度按插件独立保存；插件动态注册/注销会驱动宿主更新，失效插件自动关闭；
- 每个任务独立持久化 `Work / Chat` 类型与项目上下文；新任务默认 Chat，拖入项目即变为 Work，拖回 Chat 会解除项目绑定；Electron 会话固定保存在全局任务存储，画布项目水合不得覆盖任务列表；
- Work、Chat 与项目目录均可折叠；任务拖入时自动展开 Work 和目标项目。项目可直接发起会话并支持置顶、重命名、删除；会话支持置顶、重命名、移动、归档、恢复和删除；桌面加载与删除最后一个项目均不自动补建“未命名项目”，删除后绑定任务安全迁回 Chat；
- 项目/任务/扩展/账号菜单支持点击外部、窗口失焦和 Escape 关闭，重命名输入失焦保存、空的新建项目输入失焦取消；
- 左下角展示当前个人/团队和余额，团队切换会同步刷新 Work 项目与计费上下文；
- 已接通 `⌘K` 搜索及上下选择、`⌘N` 新任务、`⌘B` 显隐侧栏；侧栏宽度、显隐、目录折叠、置顶与归档状态均本地持久化；
- 现有画布以 `tanva.canvas` 内置插件接入；`embeddedDesktop` 模式不渲染网页项目头、账号/积分导航、Focus 全局模式或第二套小T，画布工具栏/图层/素材/缩放固定在插件容器内，不得覆盖任务边栏；React Flow 节点 MiniMap 始终保留，低细节、拖动和缩放期间也不卸载；
- 小T的 `flow_patch`、`create_presentation` 和 `edit_presentation` 会自动请求打开画布插件；Work 会话执行前以任务绑定的 `projectId` 打开并等待当前画布水合，画布快照以及建节点、连线、运行事件均校验同一项目身份，项目切换后旧操作会显式失败而不会落入新画布；
- 小T创建 GPT Image 2/Nano2 节点时，`presetPrompt` 与其他内联提示词统一外置为可见可编辑的 `textPrompt` 输入；历史节点仍可直接使用已有 `presetPrompt` 运行，禁止出现“面板有提示词、执行却报缺少输入”的双重语义；
- 新增 `tanva.artifacts` 文件工作台：消息卡与工作台都提供直接下载；PPT 卡持久化完整 deck，关闭画布或重启后仍可显示逐页缩略图、大页预览并导出 HTML/PPTX，也可回到画布编辑；Excel 由 `create_spreadsheet` 生成多工作表预览和真实 XLSX；普通文档导出 Markdown；消息复制由 Electron 系统剪贴板承接并显示成功/失败反馈；
- 新增 `tanva.media-preview` 媒体预览工具面：Electron 聊天图片点击后只在任务右侧展开，不进入最大化或全屏，支持原图下载与同组图片切换；网页端继续使用原图片预览；
- 左下角 Tanva 余额与 new-api 模型渠道额度是两套账。任何 facade 返回 `402/team_insufficient_credits` 时，前后端都会在 Luna、Terra、DeepSeek 三条线路间去重回退；用户余额充足时禁止展示“请充值”这类模型供应侧错误，全部线路均不可用才提示服务线路暂时不可用；
- “扩展”只展示/管理插件，不直接启动画布；当前任务顶栏是唯一手动开关，小T仍可自动唤起同一工具面；
- 新增 `tanva.desktop-connectors` 可信内置插件，通过受控 IPC 自动检测、手动指定并启动五类专业软件；“已找到应用”与“MCP 已连接”严格分开；小T只可打开管理工具面，不可静默启动外部应用；
- 新增官方 MCP TypeScript Client 驱动的 stdio Capability Host，可导入绝对路径配置、连接/断开并发现真实工具；小T先按需查询工具 schema，再请求调用，Electron Main 每次显示一次性原生确认。工具结果过滤二进制、内联 URL、base64 和超长文本；
- 新增桌面浏览器验收，覆盖项目内直接发起会话、Work/项目/Chat 折叠、拖拽归属、项目与会话菜单、失焦、`⌘K`、`⌘B`、画布边界、PPT/Excel 文件工作台和连接器工具面；
- macOS arm64 未签名目录包已经完成实际启动验证。

当前尚未实现五类专业软件桥接的随包分发、HTTP MCP、Utility Process 隔离、外部插件安装、签名/完整性、自动更新和正式签名公证。详细实现见 `frontend/docs/desktop/02-Electron与工具面插件实现.md`，逐项对齐状态见 `frontend/docs/desktop/04-Codex交互对齐清单.md`，JZXZ 证据与映射见 `frontend/docs/desktop/03-JZXZ能力拆解与Tanva映射.md`。
